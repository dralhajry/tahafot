# موقع «تهافت البصائر»

موقع من صفحة واحدة: تنزيل الكتاب، وفهرس يُبحث فيه بكلمة أو برقم السؤال وينقل إلى صفحة الفصل في الـPDF، وفيديوهات قناة «تهافت» تُضاف تلقائيا، وروابط الحسابات.

## الخطوة ١: املأ الإعدادات

افتح `config.js` واملأ ثلاثة أشياء:

- `youtubeChannelId`: معرف القناة، ويبدأ بـ `UC`. تجده في YouTube Studio ← الإعدادات ← القناة ← الإعدادات المتقدمة.
- `youtubeUrl`: رابط القناة، مثل `https://www.youtube.com/@tahafut`.
- `tiktokUrl`: رابط حساب تيك توك.

وما بقي فارغا من الروابط يُخفى من الموقع تلقائيا.

## الخطوة ٢: انشر الموقع على GitHub Pages (مجانا)

1. أنشئ حسابا في github.com إن لم يكن لك حساب، ثم أنشئ مستودعا جديدا عاما (Public) باسم مثل `tahafut`.
2. ارفع محتوى هذا المجلد كله إلى المستودع (Add file ← Upload files)، ومنه مجلد `.github` المخفي. إن لم يظهر المجلد المخفي في نافذة الرفع، فأنشئ الملف يدويا بالمسار `.github/workflows/update-videos.yml` والصق فيه محتواه.
3. من Settings ← Pages: اختر Source = Deploy from a branch، والفرع `main`، والمجلد `/ (root)`. بعد دقيقة يصير الموقع على `https://اسمك.github.io/tahafut`.
4. من Settings ← Actions ← General ← Workflow permissions: اختر **Read and write permissions** واحفظ. بهذا يستطيع التحديث التلقائي أن يحفظ قائمة الفيديوهات.
5. من تبويب Actions: افتح «تحديث فيديوهات القناة» واضغط Run workflow مرة واحدة للتجربة.

## كيف تعمل الفيديوهات التلقائية

كل ثلاث ساعات يقرأ GitHub الخلاصة العامة لقناتك (بلا مفتاح API)، ويكتب أحدث الفيديوهات في `videos.json`، فتظهر في الموقع بصورها وعناوينها وتواريخها. المقاطع القصيرة (Shorts) لا تُعرض في الشبكة.

وقبل أول تحديث، إن كان معرف القناة موجودا، يعرض الموقع قائمة تشغيل القناة نفسها. وإن لم يكن، يعرض دعوة إلى الاشتراك.

## نطاق خاص (اختياري)

إن اشتريت نطاقا مثل `tahafut.com`، فأضفه في Settings ← Pages ← Custom domain، واتبع تعليمات GitHub لإعداد DNS.

## تحديث الكتاب

استبدل `assets/tahafut-albasair.pdf` بالنسخة الجديدة بالاسم نفسه. وإن تغيرت أرقام الصفحات، فحدّث `pages` و`pdfSizeMB` في `config.js`، وأرقام الصفحات في `assets/chapters.json`.

## الخط

الموقع بخط «ثمانية» (Thmanyah Sans) بإذن من ثمانية، وملفاته في `assets/fonts/` بصيغة woff2 كما وردت من ثمانية دون تعديل. ولا تُنقل هذه الملفات إلى مشروع آخر إلا بإذن جديد. وعبارة «تهافت الـ» الحمراء في رأس الصفحة صورة متجهة (`assets/tahafut-word.svg`) رُسمت من خط «Hüsrev Hattı Arapça»، ولم يُرفع ملف هذا الخط نفسه، لأن رخصته غير معروفة. والتصحيحات الحمراء في قسم «من الصفحة التالية» بخط «عارف رقعة» من Google Fonts.
